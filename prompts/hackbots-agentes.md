# 🤖 Hackbots / Automação com Agentes — Prompts

> Baseado em "Hackbots: agentic security training" (Arcanum Security).

## 1. Hackbot de recon autônomo
```
Projete um hackbot local (agente autônomo) que recebe um domínio, executa recon
passivo com subfinder+httpx e gera um relatório markdown. Defina tools, memória
e guardrails de segurança.
```

## 2. Jogo ataque/defesa (red vs blue)
```
Crie um loop de agentes "jogo ataque/defesa": um agente red propõe um vetor,
o agente blue propõe a defesa, e um juiz pontua. Apenas ambiente de lab.
```

## 3. Agente de QA de segurança
```
Escreva o system prompt de um agente de QA de segurança para revisar scripts do
Mestre do PC V10 buscando segredos hardcoded e OWASP Top 10.
```
