# 📈 Prompts — Análise de Tendências

## Tech e segurança
```
Atue como analista de tendências de cibersegurança. Quais são as 5 técnicas
de ataque emergentes em 2026 e como times de defesa estão respondendo?
```
```
Analise os repositórios trending do GitHub em segurança ofensiva nas últimas
4 semanas e identifique padrões: linguagens, alvos, técnicas.
```

## IA e LLMs
```
Liste os modelos de LLM open-weight lançados nos últimos 3 meses com relevância
para desenvolvimento local (Ollama/llama.cpp), comparando tamanho, licença e
capacidade de tool calling.
```
```
Quais frameworks de agentes autônomos estão ganhando tração? Compare
arquitetura, ecossistema e maturidade.
```

## Formato de saída padrão
```
Entregue em: tabela comparativa + seção "sinais fracos" (tendências iniciais)
+ recomendação de 3 apostas para o laboratório testar.
```
