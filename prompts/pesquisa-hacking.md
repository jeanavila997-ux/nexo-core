# 🔍 Prompts — Pesquisa Hacking

> Uso educacional e em lab autorizado (LabTest-X).

## Metodologia
```
Atue como pesquisador de segurança. Explique a metodologia PTES (Penetration
Testing Execution Standard) e como adaptá-la para um laboratório pessoal.
```
```
Monte um plano de estudos de 30 dias para dominar [tópico], com recursos
gratuitos, labs práticos (HTB, THM, PortSwigger) e checkpoints semanais.
```

## Análise técnica
```
Explique como funciona [técnica/CVE] de forma didática: causa raiz, condições
de exploração, e — mais importante — como detectar e mitigar.
```
```
Analise este writeup de CTF e extraia: técnicas usadas, ferramentas, e o que
eu deveria estudar para resolver sozinho da próxima vez.
```

## Tradução de pesquisa em defesa
```
Dado este relatório de ataque, crie: (1) regras de detecção, (2) checklist
de hardening, (3) exercício de purple team para o lab.
```
