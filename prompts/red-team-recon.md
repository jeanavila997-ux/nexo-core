> Baseado na metodologia "The Bug Hunter's Methodology" (Arcanum Security).
> Uso exclusivo em ambiente autorizado / laboratório (LabTest-X).

## 1. Metodologia de Recon em 5 fases
```
Atue como um bug hunter sênior. Dado o domínio [ALVO], descreva uma metodologia
de recon em 5 fases: descoberta de subdomínios, enumeração de ASN, cloud recon,
análise de WHOIS reverso e detecção de virtual hosts.
```

## 2. Análise de .env exposto
```
Analise este arquivo .env exposto e classifique cada credencial por criticidade
e vetor de exploração possível (ambiente autorizado de teste).
```

## 3. Checklist DMARC/SPF/DKIM
```
Crie um checklist de análise de DMARC/SPF/DKIM para o domínio [ALVO] e explique
como identificar spoofing de e-mail.
```

## 4. Expansão de escopo via aquisições
```
Explique como usar aquisições corporativas (acquisitions) para expandir o escopo
de um programa de bug bounty de forma legítima.
```
