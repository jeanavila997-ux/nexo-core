## Recon / OSINT
| Ferramenta | Uso |
|---|---|
| `nmap` | varredura de portas e serviços |
| `subfinder` / `amass` | subdomínios |
| `theHarvester` | e-mails, hosts, OSINT |
| `maltego` | inteligência relacional |
| `recon-ng` | framework de recon web |
