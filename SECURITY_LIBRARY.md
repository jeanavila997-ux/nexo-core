# 🛡️ Biblioteca de Prompts e Comandos — LabTest-X

Coleção organizada de prompts e comandos de segurança, inspirada na metodologia
da [Arcanum Security](https://arcanum-sec.com) (Bug Hunter's Methodology,
Attacking AI, Red Blue Purple AI, Hackbots).

## Estrutura

```
prompts/
├── red-team-recon.md      # Recon e bug bounty (OSINT, subdomínios, DMARC)
├── attacking-ai.md        # Segurança ofensiva de LLMs e agentes
├── blue-team.md           # Defesa, SOC, detecção Sigma
└── hackbots-agentes.md    # Automação com agentes autônomos

comandos/
├── recon-kali.md          # Recon e varredura (Kali Linux)
└── blue-team.md           # Defesa e análise local (Linux/Windows)
```

## Missão do laboratório

**APRENDER → ANALISAR → TESTAR → PROTEGER**

⚠️ Todo o material é para uso exclusivo em ambientes autorizados e de laboratório.
