# 🖥️ Terminais Agênticos e TUIs

## Terminais modernos
| Terminal | Destaque |
|---|---|
| **Hyper** | extensível via JS, plugins (hyperframes) |
| **Warp** | blocos de comando, AI integrada |
| **WezTerm** | GPU-accelerated, multiplexador |
| **Alacritty** | minimalista e rápido |
| **Windows Terminal** | padrão no pc2 (WSL + PowerShell) |

## Ferramentas TUI agênticas
| Ferramenta | Uso |
|---|---|
| **Kimi Code CLI** | agente Kimi no terminal |
| **Claude Code** | agente Anthropic |
| **Gemini CLI** | agente Google |
| **Aider** | pair programming com LLM |
| **lazygit** | Git em TUI |
| **btop** | monitor de sistema |
| **k9s** | Kubernetes TUI |
