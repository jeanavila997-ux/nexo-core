# 🤖 Habilidades Kimi — Catálogo

Lista de skills e habilidades do ecossistema Kimi para usar nos projetos do lab.

## Skills úteis para o LabTest-X

| Skill | Uso |
|---|---|
| `code-vuln-audit` | Scan de vulnerabilidades: dependency audit, secret leaks, OWASP |
| `secure-code-review` | Revisão sistemática: SQLi, XSS, SSRF, OWASP Top 10 |
| `repo-audit` | Análise de Git history: hotspots, ownership, segredos vazados |
| `pipeline-blueprint` | Templates CI/CD (GitHub Actions, GitLab CI) |
| `http-load-profiler` | Load test com p50/p90/p99 e ponto de inflexão |
| `log-error-digest` | Análise de logs: clustering de erros, frequência |
| `incident-review-guide` | Postmortem blameless, RCA, 5 Whys |
| `deep-research-v2` | Pesquisa profunda com evidências |
| `database-scout` | Explorar SQLite/Postgres, schemas, ER diagrams |
| `kimi-help-center` | Dúvidas sobre produtos Kimi |
