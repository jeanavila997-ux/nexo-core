## Como aproveitar no lab

1. Clonar e estudar a estrutura:
```bash
git clone https://github.com/alirezarezvani/claude-skills
```

2. Anatomia de uma skill (padrão SKILL.md):
```
minha-skill/
└── SKILL.md    # frontmatter: name, description + instruções
```

3. Adaptar skills do Claude para o formato Kimi (mesma ideia: nome + gatilho + workflow).
